Package Diagram — Education Management System

Kiến trúc module hệ thống  ·  5 Use Cases + Core Infrastructure  ·  UML 2.x Package Diagram

Ký hiệu Package UML 2.x (folder notation): Hình chữ nhật chính (body) chứa các thành phần; tab nhỏ hình chữ L ở góc trên-trái ghi tên Package — không ghi UC0X.
Nội dung bên trong Package: Chỉ liệt kê tên Lớp / Module chính, không hiển thị thuộc tính hay phương thức. Core ghi thêm stereotype «utility» để mô tả tính chất.
– – –▷  «import» (đường nét đứt + đầu mũi tên chữ V nét đơn): Package A phụ thuộc vào Package B; mũi tên chỉ vào B (package bị nhập).
– – –▷  «use» (nhạt hơn, ký hiệu giống «import»): Package A gọi dịch vụ của B mà không nhập không gian tên. Tất cả 5 package đều «use» Core / Infrastructure.
